# Matthew Giuffre — Personal Website

## Project Overview
Personal portfolio site for Matthew Giuffre. Single-page scrollable SPA with anchor nav.

## Stack
- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Design**: Dark mode, creative/unique vibe

## Design Decisions
- Single-page scrollable (no multi-page routing)
- Dark mode first
- Creative / unique layout — not a generic template
- ui-ux-pro-max Claude Code plugin installed for design intelligence
- Google Stitch MCP connected — use to generate UI sections before coding
